# Development

## Prerequisites

- Node.js **24.15.0** (see `.nvmrc`)
- npm **11.12.1**

The repository was verified with those versions. Newer Node releases may work, but CI and the release checks use `.nvmrc`.

## Install and run

```sh
npm ci
npm run dev
```

Open <http://127.0.0.1:5173>. The dev server uses a strict port; if the port is occupied, startup fails instead of choosing another one. The first install needs network access; the running app is offline.

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start Vite. |
| `npm run preview` | Preview the production build. |
| `npm run generate` | Regenerate `src/api-types.ts` from `configs/openapi.json`. |
| `npm run typecheck` | `tsc --noEmit`. |
| `npm run build` | Type-check, then build `dist/`. |
| `npm test` | Vitest unit and contract tests. |
| `npm run test:e2e` | Playwright browser tests. |

## Tests

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

The unit/contract suite covers:

- every date and layer response against the OpenAPI schemas;
- cell-boundary mapping and out-of-range rejection;
- zero versus missing in CSV and provenance JSON;
- contextual knowledge answers and the `not_ready` fallback;
- the SHA-256 of the offline land file.

The browser suite covers the offline map, date/layer switching, grid selection, exports, the empty/not-ready/error scenarios, request races, zero-versus-missing rendering, and the absence of third-party requests. It runs at 1280×800 and 1920×1080.

## CI

`.github/workflows/ci.yml` runs on pushes to `main`, on pull requests, and on manual dispatch:

- **verify**: `npm ci`, `npm run generate`, a clean `git diff --exit-code src/api-types.ts`, `npm run typecheck`, `npm test`, `npm run build`.
- **e2e**: `npm ci`, `npx playwright install --with-deps chromium`, `npm run test:e2e`; failure artifacts are uploaded.

Node is selected from `.nvmrc`. No secrets are required.

## Project conventions

- TypeScript is strict; avoid `any` and non-null assertions unless the surrounding code already requires them.
- `src/api-types.ts` is generated. Change `configs/openapi.json`, then run `npm run generate`; commit the generated file.
- Mock responses live in `src/model.ts`; MSW handlers live in `src/mocks.ts`. Keep the four endpoint shapes compatible with the contract.
- Presentational panels live in `src/components/`; keep state and request orchestration in `src/App.tsx`.
- Do not commit `node_modules/`, `dist/`, `test-results/`, `playwright-report/`, real data, credentials, or run artifacts.
- Keep the UI strings and tests in sync when changing visible labels.

## Generated artifacts

- `src/api-types.ts` — generated by `openapi-typescript` from `configs/openapi.json`.
- `public/mockServiceWorker.js` — generated by MSW. If it needs regeneration, use the MSW CLI with the configured worker directory:

  ```sh
  npx msw init public/ --save
  ```

## Troubleshooting

- **Port 5173 in use**: stop the other process; the dev server intentionally fails rather than switching ports.
- **Mock API unavailable**: ensure the service worker is registered; hard-reload the page. `public/mockServiceWorker.js` must match the installed MSW version.
- **Playwright browser missing**: run `npx playwright install chromium`.
- **Generated types differ in CI**: run `npm run generate` locally and commit `src/api-types.ts`.
